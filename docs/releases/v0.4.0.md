# ocfp 0.4.0

This minor release combines AWS and GCP lifecycle improvements with a full
Go dependency and development-tool refresh.

## Cloud operations

- Refresh AWS and GCP bastion boot disks on the existing VM, with a journal,
  retained safety snapshots, resumable recovery, and an explicit rollback path.
- Preserve persistent bastion and artifacts data disks and adopted cloud
  networks during recovery and teardown.
- Support existing private egress and validate imported cloud topology before
  recording it in state.
- Improve native AWS and GCP load-balancer provisioning, cloud resource
  identifiers, and GCP environment initialization.
- Export observed cloud topology and canonical Vault records for downstream
  kits. Persist local state with atomic replacement.

See [AWS and GCP operations](../aws-gcp-vault-and-data.md) for configuration,
recovery commands, and limitations. Live cloud bootstrap, refresh, and kit
qualification remain separate from automated CLI tests.

## Security

SSH private-key restoration rejects bloc names containing directory traversal
or path separators and prevents key-file symlinks from writing outside the
selected SSH key directory.

## Dependencies and tools

- Require Go 1.27.3 for source builds; align CI, release containers, the
  development container, and lint execution with that patch release.
- Update `proxmox-apiclient-go/v3` from v3.10.0 to v3.11.0.
- Refresh AWS, GCP, Azure, and STACKIT SDKs and their transitive dependencies.
- Migrate Azure compute to v9, network to v10, resources to v4, and storage
  to v4. The CLI configuration interface is unchanged.
- Update golangci-lint to v2.15.0, govulncheck to v1.9.0, and GoReleaser to
  v2.18.3. Refresh pinned GitHub Actions and development tools.
- Replace the archived `github.com/golang/mock` generator with the maintained
  `go.uber.org/mock` generator.
- Remove obsolete private helpers and simplify cloud provisioning and
  recovery functions to satisfy the current lint checks.

SFTP stays on the latest stable v1 release; v2 is still a prerelease.

## Installation

```sh
brew upgrade --cask fivetwenty-io/tap/ocfp
```

Release assets include macOS, Linux, and Windows archives, Linux packages,
and SHA256 checksums. Existing installations can also replace the executable
with the archive for their platform.
